AQIB — CREATIVE STUDIO PORTFOLIO

FILES
- index.html: website structure and content
- style.css: visual design, responsive layout and animation styles
- script.js: interactive behaviour and animation controls
- assets/: portrait, CV and project/illustrative visuals

PREVIEW
Keep all files together. Open index.html in a modern browser. For best local testing, run a simple static server from this folder (for example: python -m http.server 8000) and visit http://localhost:8000.

INTERACTIONS
- Skippable cinematic intro (shown once per browser session)
- Kinetic hero phrase rotation
- Custom cursor for mouse/trackpad devices
- 3D project-card tilt and light sheen on pointer devices
- Scroll-triggered section reveals and staggered card entrances
- Qualitative animated skill bars
- Project category filters, mobile navigation and scroll progress

ACCESSIBILITY & PERFORMANCE
Animations respect prefers-reduced-motion. The custom cursor and 3D tilt are disabled on touch devices. The intro is skipped when JavaScript is unavailable or reduced motion is requested. No external animation library is required.

CONTENT NOTE
